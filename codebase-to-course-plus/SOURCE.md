# Source and adaptation

Based on [zarazhangrui/codebase-to-course](https://github.com/zarazhangrui/codebase-to-course), by Zara Zhang.

Inspected upstream commit: `ff8837ecf8e9f6ce9874ffa42e42633394a52a00`.

This package retains and adapts the upstream visual CSS, JavaScript interaction engine, and HTML interaction reference. The entrypoint, workflow/research/practice/quality references, offline shell, and Python evidence/build checker were rewritten or added for Codex and source-based learning. The JavaScript adds keyboard/reduced-motion support, localized text feedback, and cancellable chat timers; the CSS adds local font fallbacks, a narrow-screen navigation offset, and source/practice styles.
